C++ Basics

C++ is a powerful language used to build fast, efficient programs — from games to operating systems.

1. Variables & Data Types

Variables store data. C++ requires you to state the data type.

int age = 20;
double price = 9.99;
char grade = 'A';
string name = "John";

Try it: Create a variable to store your own age and name.

2. Input & Output

cout prints output, and cin reads input from the user.

cout << "Enter your name: ";
cin >> name;
cout << "Hello, " << name;

Try it: Ask the user for their age and print it back.

3. Conditionals (if/else)

Conditionals let your program make decisions.

if (age >= 18) {
    cout << "You are an adult.";
} else {
    cout << "You are a minor.";
}

Try it: Write an if/else that checks if a number is even or odd.

4. Loops

Loops repeat code multiple times.

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

Try it: Write a loop that prints numbers 1 to 10.

5. Functions

Functions are reusable blocks of code.

int add(int a, int b) {
    return a + b;
}

Try it: Write a function that multiplies two numbers.

Mini Exercise

Write a small program that asks for the user's name and age, then prints whether they are an adult or a minor.
