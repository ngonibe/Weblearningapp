WebLearningApp is a simple project built to teach the basics of HTML, CSS, and JavaScript through hands-on examples.

About WebLearningApp

Hi, I'm Joseph — the creator of WebLearningApp. I'm a student learning web development, and I built this app as part of my own journey to understand HTML, CSS, and JavaScript step by step.

WebLearningApp is a simple, beginner-friendly platform where learners can follow lessons, practice coding concepts, and build real skills at their own pace.

Why I Built This

I started this project from scratch — going from a blank page to a fully working website. Along the way, I learned about Git, GitHub Pages, responsive design, and debugging real code. I wanted to share that same learning experience with others.

What's Next

I'm continuing to improve WebLearningApp, adding more lessons, better design, and new features — including plans to turn it into a mobile app.
