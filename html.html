HTML Basics

HTML (HyperText Markup Language) is the skeleton of every webpage. It uses "tags" to structure content.

1. Headings

Headings go from <h1> (biggest) to <h6> (smallest).

Example:

<h1>Main Title</h1>
<h2>Subtitle</h2>

Try it: In script.js's page, write an <h3> tag with your name.

2. Paragraphs

The <p> tag defines a block of text.

<p>This is a paragraph.</p>

Try it: Write two paragraphs about your favorite hobby.

3. Links

The <a> tag creates a clickable link using the href attribute.

<a href="https://example.com">Visit Site</a>

Try it: Create a link that goes to your Lessons page.

4. Images

The <img> tag displays a picture using src (source) and alt (description).

<img src="photo.jpg" alt="A photo">

Try it: Add an image of your choice to your About page.

5. Lists

Unordered lists (<ul>) use bullets. Ordered lists (<ol>) use numbers.

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

Try it: Make a list of 3 things you want to learn this month.

6. Buttons

The <button> tag creates a clickable button, often used with JavaScript.

<button>Click Me</button>

7. Divs (Containers)

<div> groups content together, often for styling with CSS.

<div>
  <h2>Card Title</h2>
  <p>Card text.</p>
</div>
