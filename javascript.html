javascript Basics

javascript makes your page interactive — responding to clicks, input, and more.

1. Variables

Variables store data using let, const, or var.

let name = "John";
const age = 20;

Try it: Create a variable with your own name and log it.

2. Console Logging

console.log() prints messages to the browser console — useful for checking your code.

console.log("Hello World!");

Try it: Open the browser console (F12) and try logging your own message.

3. Functions

Functions are reusable blocks of code.

function greet() {
  alert("Hello!");
}

Try it: Write a function that shows an alert with your name.

4. Events

Events let JavaScript respond to user actions, like clicks.

button.addEventListener('click', () => {
  alert("Button clicked!");
});

Try it: Add a second button to your Home page that shows a different alert.

5. Changing Content

JavaScript can change what's on the page using the DOM.

document.querySelector('h1').textContent = "New Title";

Mini Exercise

Add a button that, when clicked, changes the heading text on this page to say "You clicked me!"
