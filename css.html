css Basics

css (Cascading Style Sheets) controls how your HTML looks — colors, spacing, fonts, and layout.

1. Selectors

A selector targets which HTML element to style.

p {
  color: blue;
}

Try it: Change the color of all your <h2> tags to green.

2. Colors and Backgrounds

body {
  background-color: lightyellow;
  color: darkblue;
}

Try it: Give your About page a light blue background.

3. Text Styling

h1 {
  font-size: 40px;
  text-align: center;
  font-weight: bold;
}

Try it: Make your paragraph text italic using font-style: italic;

4. Box Model (Padding & Margin)

div {
  padding: 20px;
  margin: 10px;
  border: 1px solid black;
}

Try it: Add padding around your button so it looks bigger.

5. Hover Effects

button:hover {
  background-color: red;
}
