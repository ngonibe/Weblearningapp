# WebLearningApp

A multi-page educational website teaching HTML, CSS, JavaScript, and C++ basics — built for learners across Ghana.

## Live Site
https://ngonibe.github.io/Weblearningapp/

## Features
- Home page with introduction
- Lessons page with embedded video tutorials for HTML, CSS, JavaScript, and C++
- Practice page
- Quiz page to test knowledge
- About page
- Mobile-responsive design

## Built With
- HTML5
- CSS3
- JavaScript
